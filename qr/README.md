# QR de las páginas

- `qr-trivia-github.png` / `qr-sorteo-github.png` → apuntan a **GitHub Pages**
  (`https://stevens507.github.io/aws-saa-c03-estudio/…`). Son los que conviene
  repartir: la página es pública y no hace falta cuenta de nada.
- `qr-trivia.png` / `qr-sorteo.png` → apuntan a las versiones publicadas en
  claude.ai, que hay que compartir desde la propia página para que se vean.

Para que funcionen los de GitHub Pages hay que activar Pages una vez:
**Settings → Pages → Deploy from a branch → `main` / `root`**.
